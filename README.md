# Brazos PLM downloads

[Download the latest Windows installer](https://github.com/azlo-aj/brazospdm-downloads/releases/latest).

This repository contains installer and automatic-update files only. Brazos PLM requires an authorized organization account to access company data.

Keep Brazos PLM installed under the same Windows user account for updates. The first update-enabled version must be installed manually.

The latest release and one previous installer are retained so downloads already in progress can finish. Application source and company data are not stored in this repository.
